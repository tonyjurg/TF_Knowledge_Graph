About TF Knowledge Graph

This project turns a Text-Fabric dataset into a knowledge graph that can be exported as JSON and explored visually. It provides two Python notebooks and an example generated from N1904-TF.

From dataset to visualization

  1. Text-Fabric datasetThe N1904 dataset supplies the example data.
  2. Create the knowledge graphGenerate the JSON graph and Cytoscape elements.
  3. Generate the visualizationAdd node positions and create the interactive HTML file.
  4. Explore the graphInspect nodes and edges in your browser.

Two kinds of output

JSON files provide a machine-readable representation of the graph. The repository also illustrates their use as grounding material for a custom GPT.

The interactive HTML graph uses Cytoscape.js to display the graph and provide node and edge information through context menus.

Project and source

TF Knowledge Graph is maintained by Tony Jurg. The notebooks and generated example files are available in the GitHub repository.
